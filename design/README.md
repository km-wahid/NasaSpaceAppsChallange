# Design references

The HTML files in this directory are archived visual concepts, not production application screens
or data integrations. References in them to SMAP, Landsat, Sentinel-2, MODIS NDVI, MOD16A2,
satellite synchronization, model versions, or NASA partnership are illustrative prototype copy and
must not be presented as current OrbitAgro capabilities.

The production application currently uses:

- NASA POWER historical climate data, cached before recommendation generation; and
- NASA EOSDIS GIBS MODIS Terra corrected-reflectance true-colour tiles for visual context only.

OrbitAgro does not currently calculate recommendations from satellite imagery, NDVI, remotely
sensed soil moisture, land-surface temperature, or evapotranspiration products. NASA does not
endorse or formally partner with this project.

Use the production source under `app/` for demonstrations, screenshots, and capability claims.
