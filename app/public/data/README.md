# Bangladesh district boundaries

`bangladesh-districts.geojson` contains simplified ADM2 district boundaries from
the geoBoundaries BGD ADM2 release (`BGD-ADM2-16705992`). The source identifies
Bangladesh Bureau of Statistics and OCHA ROAP, and is licensed under CC BY 3.0
IGO. Geometry was simplified locally for mobile delivery; district names and
boundaries were not otherwise edited.

Source: https://www.geoboundaries.org/api/current/gbOpen/BGD/ADM2/
